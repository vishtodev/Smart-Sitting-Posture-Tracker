# Smart-Sitting-Posture-Tracker
An IoT-based smart posture monitoring system that tracks sitting posture in real time using motion sensors and a Flutter mobile application.

## Overview

Smart Posture Monitor helps users maintain healthy sitting posture by detecting bad posture events and providing real-time monitoring, statistics, and posture analysis.

The system combines:

- Embedded hardware sensor module
- Wireless communication
- Flutter mobile application
- Weekly posture analytics
- Gamification features

---

## Features

- Real-time posture monitoring
- Good vs bad posture detection
- Multiple sensitivity modes
  - Strict
  - Moderate
  - Lenient
- Weekly posture analytics
- Sitting time tracking
- Bad posture event tracking
- XP and level system
- Coin rewards system
- Clean dark-themed UI
- Bluetooth/Wireless connectivity support

---

## Tech Stack

### Mobile App
- Flutter
- Dart

### Hardware
- MPU6050 Sensor
- ESP32
- Battery-powered wearable module
- Vibration motor

---

## Working Principle

1. MPU6050 continuously tracks body orientation.
2. Sensor data is processed by the microcontroller.
3. Posture angle is compared against selected threshold mode.
4. Bad posture events are detected.
5. Data is sent to the Flutter app wirelessly.
6. App visualizes analytics and posture statistics.

---

## Modes

| Mode | Threshold |
|------|-----------|
| Strict | Highly Sensitive |
| Moderate | Balanced |
| Lenient | Relaxed |
